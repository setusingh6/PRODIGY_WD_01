# PRODIGY_WD_01 – Responsive Webpage 🌐

## 📌 Project Overview
This project is a **responsive webpage** created as **Task 1** of the **Web Development Internship at Prodigy InfoTech**.  
The main goal of this task was to design and develop a webpage that adapts smoothly to different screen sizes including desktops, tablets, and mobile devices.

---

## 🎯 Objective
- To understand the fundamentals of **responsive web design**
- To create a clean and user-friendly layout
- To ensure proper responsiveness across all devices using modern CSS techniques

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the webpage  
- **CSS3** – Styling and layout  
- **Media Queries** – Making the webpage responsive  

---

## ✨ Features
- Fully responsive layout  
- Mobile-first design approach  
- Clean and modern UI  
- Cross-device compatibility  

---

## 📚 What I Learned
- Basics of responsive web design  
- Effective use of **media queries**  
- Structuring webpages using semantic HTML  
- Improving UI using CSS styling techniques
